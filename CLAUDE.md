# Fox

A coding agent built from scratch in TypeScript, using the Gemini API. 

## Goal

The goal is to understand agentic patterns from first principles by studying the following:
1. [Flue framework](https://github.com/withastro/flue) and implementing the core ideas independently. The codebase for Flue is available at `/tmp/flue` (cloned from the GitHub repository).
2. [Pi](https://github.com/earendil-works/pi). The codebase for Pi is available at `~/Desktop/learn/pi` (cloned from the GitHub repository).
